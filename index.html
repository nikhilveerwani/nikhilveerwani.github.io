How I work

Four habits behind the numbers

Reconcile before you report

Every new view is tied back to source counts before anyone sees it. If two numbers disagree, I find the rows that explain the gap.

One metric, one definition

Logic lives in the warehouse, not in twelve dashboards. When a rule changes, it changes once, with a dated note on what moved.

Ship the alert, not just the dashboard

People act on Slack and on lists of names. A dashboard nobody opens hasn't shipped, so the output is a message with the leads to call.

Call a measurement fix a measurement fix

When a number jumps because the measurement was wrong, I say so. Trust in the data is worth more than one good-looking week.
